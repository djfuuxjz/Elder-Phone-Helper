# 老年人手机助手 PRD

版本基线：Android V0.3.0；包含 2026-11-05 的查看器交互更新及目录整理。本文为当前需求口径；旧 MVP 文档已被当前需求替代，过时副本已清理。需求已实现不等于真机验收通过。

## 1. 产品目标

帮助不熟悉手机操作的老年人，用自然语言表达目标，在真实 Android 页面上完成任务。提供默认人工引导和用户明确开启的有限自动操作能力，能解释每次判断、执行、失败和完成依据。

保留“给女儿打视频电话”快捷任务用于兼容与回归；自定义任务必须始终围绕本次用户目标，不把联系人、应用或渠道改成固定值。目标有歧义时请求澄清。

## 2. 用户与页面

| 页面 | 当前职责 |
|---|---|
| 任务 | 语音/文字输入、核对识别文字、启动自定义目标；底部附近保留固定视频快捷任务 |
| 我的 | 权限状态、模型配置、图片能力开关、默认关闭的自动点击/返回开关、流程库与 Debug |
| 引导浮层 | 单步文字/语音、高亮、重试和停止，明确人工或自动方式；完成提示显示约 1 秒后关闭 |
| Debug | 本机运行日志、证据附件、统计、导出、标注与清理，不作为用户历史任务产品 |
| 电脑查看器 | 离线查看各步骤、图树、模型内容、执行和诊断，复制完整本步日志 |

语音调用系统识别服务，不承诺所有机型存在服务或完全离线。没有识别能力时文字输入可继续使用。

## 4. 任务与流程

支持 13 项保守匹配的只读模板：微信视频、微信语音、微信文字、微信照片、微信扫一扫、普通电话、短信、调大字体、调亮屏幕、调大媒体音量、闹钟、最近照片、天气。

模板保存语义与参数，不缓存节点 ID 或坐标。渠道未说明时不擅自替换微信/短信；对象、内容、时间、城市等不明确时不得猜测。未匹配目标由模型基于真实页面处理。

原固定视频流程可成功复盘、保存版本、自动启用、锁定、试运行和回退；锁定、停用或任务期间切换版本时不得覆盖人工选择。13 项模板目前只读，不自动复盘晋升。失败记录和未知来源事件只能作为实际证据，不把未走过的捷径描述为已验证路线。

## 5. 决策与执行闭环

观察稳定候选页面 → 采集 UI 树和截图 → 检查采集一致性 → 保存证据/准备请求 → 发送模型 → 校验响应和页面时效 → 人工引导或有限自动执行 → 观察操作及页面变化 → 验证当前目标。

- 每次用于决策的观察都尝试截图；不因文本模型而省略本地截图。截图失败必须说明具体系统原因。
- 树与图通过采集前后指纹、窗口尺寸和事件版本检查关联；变化时废弃并重新观察，不承诺操作系统未报告变化下的原子一致性。
- 遍历上限 3000、深度上限 50、有效节点上限 700；空容器不占有效节点名额，交互节点优先保留，记录截断原因。
- 无节点时模型应返回 JSON null；仅 target_node 的空字符串/纯空白兼容为 Kotlin null。字符串“null”、未知/旧节点不视为空值。
- CLICK 必须有有效节点或坐标；保留屏幕边界、节点归属、节点与坐标重叠、目标区域小于屏幕 60% 的规则。confidence 验证 0..1，不作为是否接受的硬门槛。
- `open_app` 只能使用实际查询到的可启动应用。系统启动未通过前台验证时，允许 GUI 的模式才尝试唯一可见图标；仍失败提示人工处理，不猜包名、API 或 Deep Link。
- 人工模式的 click 不触发自动手势。“已展示”不能记录为“已执行”；手势派发回调也不代表目标达成。
- 自动输入和自动滚动未实现，必须明确人工降级。

## 6. 完成与延迟

精确“打开/启动某应用”的完整目标可依据稳定前台包确认；复合目标不能因此提前结束。其他目标要求模型 complete/true 和非空当前证据。文本模式需有当前节点文字可核对；图片模式仍依赖模型理解，并非形式化语义证明。

成功确认后立即更新界面，截图保存、日志落盘和复盘不应阻塞提示。记录稳定等待、截图、请求排队、模型耗时、证据首次观察、完成确认和成功提示时间。

200ms 轮询、100ms 截图隐藏等待是当前配置，不是真机性能结果。没有达成统一成功率、延迟或步数门槛的实测结论，不能写成已验收指标。

## 7. 诊断、隐私与查看器

失败分别记录 stage、error_code、rule、expected、actual，并关联会话、步骤、尝试、请求、快照和附件。解析错误、规则拒绝、采集失败、过期、取消、执行失败分开呈现。手机显示简短原因，电脑保留详情。

系统报告的点击、滚动、输入变化、返回键和窗口事件要标明来源及可观察限制；不能仅凭页面变化推断用户点击。输入事件不记密码/验证码原文，可编辑字段值不写入树；截图仍可能含私人信息。API Key 加密存储，日志需脱敏。

电脑查看器要求：默认全图适配当前窗口，日志列独立滚动；原图/节点叠加切换，短编号与节点列表联动；左侧标题显示具体建议/动作，并标明建议与执行来源；一键复制本步全部事件、模型数据、诊断和 UI 树，截图本体另附。复制失败提供手动复制方式。离线查看不自动上传。

## 8. 验收要求

| 用例 | 必须满足 | 当前证据 |
|---|---|---|
| 空节点坐标样例 | 1200×2670 下合法坐标通过；空白归 null | 自动测试通过 |
| 非法目标 | 越界、旧节点、不重叠、过大区域仍拒绝 | 自动测试通过 |
| 失败诊断 | 具体规则和实际值能到日志查看器 | 程序及查看器测试通过 |
| 图树一致性 | 变化废弃、缺失说明、引用可打开 | 模拟测试/源码验证；真机待补 |
| 空容器与截断 | 600 空容器后的按钮保留，预算原因可追踪 | 自动测试通过 |
| 模式和应用打开 | 人工模式不自动点，系统优先、GUI 有界降级 | 自动测试通过；实际权限和页面待补 |
| 操作记录 | 不把建议/派发/未知来源当确定用户操作；不记输入原文 | 自动测试通过；真实事件覆盖待补 |
| 完成 | 空证据不完成，打开应用不等于复合目标完成 | 自动测试通过；真实语义误报率待补 |
| 查看器 | 常见桌面窗口全图可见、节点对齐、标题具体、复制完整 | 22 项测试和浏览器验证通过 |
| 真实效果 | 统计成功率、错误引导、调用、延迟、恢复和误报 | 未完成受控真机统计 |

真实验收应固定机型、系统、目标应用版本、模型及模式，每类起点建议至少重复 5 次，异常场景至少 3 次；这些是测试安排，不是已完成次数。失败、取消和超时均计入统计，不从分母剔除。

## 9. 不在当前范围
