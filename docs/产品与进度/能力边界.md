# 当前能力与限制

V0.3.0，2026-11-05。本文描述实现，不替代真机验收。

已实现：语音/文字目标输入；页面读屏与每次决策截图；目标结构和坐标校验；分阶段诊断；系统启动优先；默认人工与可选点击/返回；13 项只读模板与固定视频版本库；可观察系统事件；当前证据完成判断；图树联动的离线查看器及整步复制。

有限能力：GUI 仅点击/返回；输入和滚动人工完成。打开应用仅使用实际启动入口和有界可见图标降级，不保证任意 Deep Link。截图受安全窗口、频率与权限限制；采集有预算；树和图非操作系统原子快照。无障碍事件不能确定所有输入来源，也不能覆盖全部返回手势。

完成限制：只有精确的单一打开目标可按前台包本地验证；其他目标仍依赖模型语义理解。非空证据及文本匹配不等于绝无误判。

数据限制：API Key 加密、日志脱敏、输入事件不记原文；截图和页面文本仍可能含隐私。查看器本地读取，主动复制或分享由用户决定。

尚未实现：自动输入/滚动、独立 ASR、账号与用户历史任务、新模板自动学习晋升、支付能力。未完成新版全任务真机成功率和完成延迟统计。测试证据见 TEST_REPORT.md。
