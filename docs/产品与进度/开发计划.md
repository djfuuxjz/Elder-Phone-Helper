# 下一阶段开发与验收计划

基线：V0.3.0 Android + 最新查看器；2026-11-05。旧 V0.1 分阶段计划已被本计划替代，不能把其中“不做语音/自动操作”作为当前约束。

## 已完成

语音/文字目标输入；固定任务与 13 项只读模板；空节点解析；结构化诊断；每次决策图树证据；节点叠加查看器；系统应用启动与可选 GUI 点击/返回；系统操作事件；完成证据与分项计时；截图全图适配、动作标题与复制。179 项安卓发布测试和最新 22 项查看器测试已有通过记录。

## 下一阶段优先级

| 优先级 | 工作 | 退出条件 |
|---|---|---|
| P0 | 处理签名与安全升级、导出备份 | 测试设备能安装目标 APK，旧日志/流程不因卸载丢失 |
| P0 | 真机截图、图树一致性与操作权限 | 每次决策附件可回看；权限不足、页面变更原因可追踪 |
| P0 | 完成误报与延迟实测 | 明确目标、证据、确认和提示时间；复合目标不提前完成，形成真实数据 |
| P1 | 13 项模板分组验收 | 逐项记录成功、失败、绕路、歧义，未通过项不标为可用保证 |
| P1 | 真实语音和文字输入兼容性 | 无语音服务、取消、识别错误、小屏大字有明确降级 |
| P1 | 迁移旧架构检查脚本 | 允许受控点击/返回，同时校验默认人工、权限和执行后验证 |
| P2 | 评估自动输入/滚动或模板晋升 | 单独明确需求、隐私、执行与验证规则后实施；当前不视为已实现 |

## 验收安排

先在备用设备或原签名构建上测试。使用无破坏性的应用打开/设置任务，再开展已约好的联系人测试。固定机型、系统、应用和模型；首页、中间页、点错、断网、权限不足、取消、过期响应分别留完整日志。保留建议、自动派发、系统事件及后续页面证据，不能用页面变化替代确定用户操作。

性能按 stable_wait_ms、capture_latency_ms、queue_latency_ms、latency_ms、evidence_to_confirmation_ms、confirmation_to_display_ms 分析；没有真机数据前不承诺提升百分比。每阶段交付包含实现、必要回归、日志和未解决项。
