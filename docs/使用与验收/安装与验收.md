# 安装与真机验收

基线 V0.3.0，2026-11-05。当前 APK 位于 ../dist；旧版本在 ../archive/发布版本。

## 安装前

先在旧版导出日志和需要的流程。当前 V0.3.0 与旧 V0.2.0 调试证书不同，不能保证覆盖升级；优先备用设备，或使用原签名构建。不要未经备份卸载旧版。需要 Android11+、可用网络和自己的模型服务凭据。

## 配置与开始

安装后在“我的”开启无障碍服务并确认连接，填写 HTTPS 模型地址、模型名和 API Key。图片开关与真实服务能力一致；默认不启用自动点击/返回。语音依赖手机识别服务，确认或修正识别文字后启动；不可用时文字输入。

先测试“打开设置”，再测“打开设置并调大字体”。前者需真实前台验证，后者不能仅打开就成功。通话、发消息等测试先安排好对象。

## 必测清单

| 类别 | 操作 | 验收点 |
|---|---|---|
| 模式 | 人工模式收到 click；开启自动后再测 | 前者只提示，后者才派发支持动作，输入/滚动明确人工 |
| 启动 | 有效入口、入口受限、无唯一图标 | 系统优先；有界 GUI 降级或人工提示，不把 API 返回当完成 |
| 采集 | 正常页、快速切页、安全窗口、权限不足 | 树图关联，变更废弃；缺失有原因与原始错误码 |
| 节点 | 空节点有效坐标、越界、旧节点、大框 | 兼容仅限空 target_node，关键拒绝仍有效 |
| 网络 | 断网、超时、错误密钥、取消、过期 | 原因与阶段区分，无永久等待或错误成功 |
| 行为 | 人工点、滑动、输入、返回 | 系统事件与建议关联，来源不确定明确标注，不出现输入原文 |
| 完成 | 最后一步仅建议、仅派发、目标真达成 | 前两者不等于完成；记录证据、确认和展示时间 |
| 流程 | 参数化联系人、渠道有歧义、未匹配目标 | 不改目标，不擅自选渠道；模板不可冒充真机验证 |
| 语音/适老 | 取消、无服务、识别错、小屏大字 | 可编辑/重试/文字降级，入口可达 |

## 导出与电脑查看

任务及复盘、证据写入结束后，从 Debug 导出完整 ZIP。解压并打开 ../日志查看器/index.html，选择完整运行目录。检查每个请求的图、树、输入输出、执行/行为与具体诊断。

右图应完整适配窗口；中间长日志独立滚动；左侧显示动作；复制本步应包含原始事件与 UI 树，复制受限时出现手动弹窗。旧日志缺少的截图不能补回。

## 记录效果

固定设备/系统/目标应用版本、模型、执行模式和起点。每种起点建议至少5次，异常场景至少3次；保留失败和取消，不只统计成功样本。记录真实成功率、错误引导、恢复、调用、完成误报及分项耗时。新版端到端延迟尚无统一真机实测结论。
