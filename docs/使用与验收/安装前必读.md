# V0.3.0 安装前必读

此版本由当前电脑重新构建，签名与原 V0.2.0 安装包不同，通常不能直接覆盖安装。

请先在旧版导出需要保留的调试日志与流程。优先使用备用手机验收，或使用原开发机的签名密钥重新构建。不要未经备份直接卸载旧版；卸载会删除应用数据。

默认仍为人工引导。可在“我的”开启自动点击/返回；输入与滚动仍人工操作。查看完整更新和手机验收步骤，请打开本目录 RELEASE_0.3.0.md 和 INSTALL_AND_TEST.md。

电脑日志查看器可以直接使用，无需重装手机。打开开发工程中的“日志查看器/index.html”，刷新已打开的页面，再导入完整日志文件夹。新截图与操作事件必须由新版采集，无法补回旧日志缺失内容。
