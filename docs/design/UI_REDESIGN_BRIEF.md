# 温馨猫咪适老化界面改版要求（尚未实施）

本次拟开发仅改变外观，不涉及任何功能改动，不影响现有功能。当前V0.1.5尚未实现本设计。

## 风格

参考references/style-01.png至style-03.png的圆润手绘猫咪，及style-04.png至style-07.png的适老化视觉原则。奶油白/米色底色、柔和橙黄主色，浅绿/浅蓝点缀，深色清晰文字，大圆角、轻阴影、充足留白。可爱但不妨碍阅读，不照搬海报品牌或增加图中的支付/健康等业务。

## 页面

保留“任务”“我的”导航、给女儿打视频电话入口、模型配置、权限、Debug和流程库全部功能；统一字体、卡片、图标、配色。图标配文字，不藏功能或新增语音自定义、登录、历史记录。

## 猫咪＋气泡悬浮窗

猫咪配圆角气泡显示现有指引，大字、完整文本。保留停止/重试/从当前页开始等控件、拖拽、位置记忆、边界限制、目标避让、高亮与点击透传。透明装饰不扩大触摸拦截范围，拖动不干扰按钮。
停止仍清除浮层并返回App；成功仍显示1秒后关闭，不由动画延时。猫咪不抢占无障碍焦点。

## 适老化

文字高对比、图标有文字语义、操作区域至少48dp，主要按钮建议56—64dp；足够间隔。适配字体放大、不同屏幕、系统栏/键盘，不裁切重要提示，不闪烁晃动；保留现有TTS和无障碍语义。

## 禁止改动

不修改模型接口/提示词/协议/节流，UI Tree/截图/坐标/校验，任务状态机/完成/重试/停止，流程复盘/自动启用/锁定/回退，日志/导出/权限/密钥存储，以及按钮行为和操作流程。只调整布局样式、颜色、字体、间距、图标、插画和背景等展示资源。参考图的二次确认/撤销等建议不作为新增功能要求。

## 交付

提供真实运行截图并检查大字体、拖拽、按钮、高亮、透传、停止和成功1秒结束。运行既有回归并补充必要界面测试，禁止删除跳过或降低验收标准。交付可覆盖安装APK，区分本地验证和待真机检查。
