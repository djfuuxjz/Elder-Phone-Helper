# 老年人手机助手

当前 Android 版本 **V0.3.0 / versionCode 10 / Android 11+**。本文依据当前源码、交付记录和最新日志查看器整理，代码与功能基线日期为 2026-11-05；本轮文档及目录维护完成于 2026-11-06。

助手根据用户用语音或文字表达的目标，观察当前手机页面，给出高亮、文字和语音提示。默认人工操作，可在“我的”开启自动点击和返回；输入、滚动仍需人工完成。打开应用优先使用实际可用的系统启动入口，并观察前台页面验证结果。

## 安装与使用

1. 先导出旧版需要保留的日志和流程。V0.3.0 当前交付包与 V0.2.0 的调试签名不同，不能保证覆盖安装；优先备用设备验证或使用原签名重新构建，不要未经备份直接卸载。
2. 安装当前 APK，开启“我的 → 无障碍设置”。填写自己的 HTTPS 模型地址、模型名和 API Key。当前默认字段为 `https://api.deepseek.com` / `deepseek-flash`，其实际可用性取决于服务账户。
3. 只有模型实际支持图片时开启图片输入。文本模型仍会尝试保存本地截图，但不会把图片放入模型请求。
4. 输入目标，核对识别文字并开始。默认人工跟随提示；只有明确开启自动模式才自动点击/返回。系统打开应用是独立能力，默认可尝试。
5. 不确定或失败时查看具体原因，重试前确认当前页面；“停止”结束引导并清除浮层。
6. 等待复盘和证据保存结束后，在 Debug 导出完整运行 ZIP，再在电脑解压查看。实际发起通话或发消息会影响联系人，验收前应安排好测试对象。

语音依赖手机已有识别服务，可能联网；未集成独立 ASR，也不保存录音。识别服务不可用时使用文字输入或键盘语音。

## 流程与完成边界

13 项模板包括微信视频、微信语音、微信文字、微信照片、微信扫一扫、普通电话、短信、字体、亮度、媒体音量、闹钟、最近照片和天气。模板保留联系人、内容、时间等参数，不保存坐标，不替换用户目标。渠道不明或匹配不明确时由模型澄清或探索。

只有原固定视频任务进入可学习版本库。新模板不会因一次模型成功就自动晋升或覆盖。复盘使用真实事件及证据，不能把“已展示建议”写成用户已经执行。

完整目标恰好是打开/启动某个已安装应用时，前台包一致才可本地完成；“打开设置并调大字体”不能仅因设置打开就完成。其他目标要求模型 complete/true 及非空当前证据。文本模式还要求证据与当前节点文字可核对；图片模式的语义判断仍依赖模型，不能保证永不误判。

## 查看日志

打开 `日志查看器/index.html`，导入一次运行的完整文件夹。刷新页面后需要重新导入。

- 左侧以“第几步 · 具体动作”显示；尝试次数在中间详情，不把建议等同执行结果。
- 右侧截图完整适配可用高度；可放大查看，按 Escape 返回。节点详情/列表按需展开。
- 中间可切换事件、输入、输出、UI 树和原始记录，点击“复制本步日志”复制完整文本及树数据。截图本体需另外附给 AI。
- 查看器离线读取，不自动上传。用户主动复制分享的日志可能包含联系人、聊天及截图中的私人信息。

## 构建与验证

需要 JDK17、Android SDK35、Build Tools35.0.0；Gradle8.11.1、AGP8.9.2、Kotlin2.1.20。配置本机 SDK 路径后执行：

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
node --test 日志查看器/tests/test-geometry.cjs 日志查看器/tests/test-ui.cjs
node 日志查看器/tests/test-integration.cjs
```

查看器浏览器测试使用 Node22 和 Mac 默认 Chrome 位置。旧夹具回归 `test-core.cjs` 还需 LOG_FIXTURE 指向规定的本机导出样本，仓库不附私人日志。

`app/build/` 为可重建产物，本次整理中清理；需要时重新构建。过时的架构/APK 检查器、原开发机启动脚本和旧查看器回归入口已删除，不作为当前命令。当前 tools 保留日志统计、其回归测试和安卓测试报告汇总脚本。

## 仍未实现与限制

未实现自动输入/滚动、独立 ASR、账号登录、用户历史任务产品、13 项模板自动学习晋升或通用第三方 Deep Link 支持。支付任务不在范围内。

安全窗口、无障碍事件、应用可见性和后台启动受系统限制。树和截图通过前后读取与事件检查保证尽量一致，Android 不提供原子树图快照；无法声称记录完整触摸轨迹或所有返回手势。新版完成延迟只有分项计时，尚无受控真机对比结果。
