# 当前流程库

基线 V0.3.0，2026-11-05。流程提供参数化语义上下文，不执行手机操作，也不缓存屏幕坐标。实际动作由当前人工/自动模式处理。

## 固定任务版本库

兼容原视频快捷任务；保存 name、task_key、steps、来源运行、基础版本和理由。支持新建/导入、编辑生成新版本、试运行、启用、锁定和回退。成功复盘可自动保存并启用新版本；当前版本锁定、停用或中途人工切换时只保存，不覆盖人工选择。试运行也不能替换无关默认版本。

联系人由本次目标和当前页面确定，不恢复精确姓名或 confidence 阈值拦截。联系人检索阶段保留优先搜索的流程规则；已移除旧文档中“自动纠正搜索框/加号位置”等不再存在的业务拦截。

## 13 项只读模板

微信视频、微信语音、微信文字、微信照片、微信扫一扫、普通电话、短信、字体、亮度、媒体音量、闹钟、最近照片和天气。自定义目标保守匹配；渠道不明确时不擅自选择，未匹配则由模型处理。模板中的联系人、内容、时间、城市等以实际 goal 为准。

模板目前只读，不参与自动成功复盘晋升，也不因一次调用成功就覆盖。模板存在不代表已完成全部真机评测。

## 证据与完成

复盘区分模型建议、展示指引、自动派发、系统报告事件和验证结果。来源不确定的事件不能归因为确定用户操作；页面变化不能直接证明某一次点击。未验证捷径需写明待验证，不声称全局最优。

只有当前目标和当前页面证据满足完成条件才终止。精确打开应用目标可本地验证，其他目标依赖模型证据；不再使用旧版本的视频页面词语本地识别逻辑。成功提示先展示，复盘后台进行；失败不撤销已确认的任务结果，新任务/停止可取消旧复盘。
