# 当前工程文件用途

已按用户要求直接删除额外备份与过时资料，不另外备份。所有旧 APK 和源码软件包保留。

目录：app 为源码；tools 为当前工具；日志查看器为唯一当前查看器；docs 为有效文档；dist 为当前软件包；archive/发布版本为旧软件包。
