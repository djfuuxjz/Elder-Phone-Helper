# 小米 15 安装与首轮测试

此包是 Android 11 及以上的开发测试版。完整产品功能已在源码中接入；真实手机、微信页面与实际模型效果仍需实测。

## 安装与配置

1. 将交付的 `phone-assistant-0.1.5-debug.apk` 传到手机，按系统提示安装“手机助手”。它使用独立包名，不覆盖其他助手。
2. 打开“我的”→“无障碍设置”，找到“手机助手 · 操作引导”并开启，返回 App 确认显示“无障碍服务已连接”。若系统提示受限或阻止开启，请记录系统提示，按本机系统设置提供的流程处理。
3. 在“我的”填写你自己的 DeepSeek API Key，点击保存。默认地址 `https://api.deepseek.com`，默认模型 `deepseek-flash`，图片能力默认开启。模型名可修改为账号实际可用的模型；纯文本模型要关闭图片能力。
4. API Key 在手机本地加密保存；聊天里不需要发送密钥。没有填写密钥时无法执行真实模型任务。
5. 确认微信已登录、只有一个能明确识别的“女儿”联系人。与对方约定测试，避免打扰。

默认图片模型依据：[DeepSeek 官方文档](https://api-docs.deepseek.com/guides/vision/)。当前账号的模型权限、余额、网络和真实响应尚未验证，实际错误可在 Debug 中查看。

## 先做一轮

1. 在“任务”点击“给女儿打视频电话”，阅读数据使用提示并开始。
2. 助手会请求系统直接打开微信。若系统阻止，请按提示手动打开后重试。微信内操作仍由你亲自完成。
3. 等待提示出现，亲自点击高亮位置；需要返回、滚动或输入时按提示手动操作。
4. 检查高亮是否准确、目标能否点击、文字与播报是否一致。按住引导栏顶部或提示文字可拖动位置；点击“停止”会清除浮层并返回助手。
5. 发起与“女儿”的视频呼叫后，检查助手是否给出完成反馈，随后可立即手动挂断，无须对方接听。
6. 如遇错误指引，用“停止”结束；不要为了测试而继续执行错误操作。记录所在页面与步骤。

首次测试建议从已打开的微信首页开始，成功后再测试桌面等其他起点。这只是排查顺序，不改变验收要求。

## 查看与反馈问题

“我的”→“Debug · 开发日志”→选择对应运行标识：

- 点击 request/response/decision/guidance 等事件，查看输入、原始输出、解析结果、耗时和错误。
- 点击“查看 UI Tree”或“查看截图”，检查模型实际看到的页面。
- 停止任务后点击“填写真机验收标注”，填写用例编号、实际成功与否、错误指引次数及设备/微信版本。
- 点击“导出本次调试包”，选择手机保存位置。分享给开发者前确认其中的聊天文字、联系人和截图适合提供。
- “清理全部调试记录”会删除本机调试文件；请先导出需要保留的记录。

模型返回完成不是人工验收结论。只有实际向正确联系人发起了视频通话，才勾选人工成功。

## 当前实施边界

- 已通过的自动化测试不等同于小米 15 或微信真实成功率。
- V0.1.2 已移除 confidence 数值拦截及固定联系人匹配，模型结合实际备注判断；App 继续检查有效目标、页面状态和真实呼叫证据。
- 无法判断页面时提示重试；不保证解决任意系统弹窗、账号异常、重复联系人或所有微信版本。
- 当前使用手动重试。每步最多 3 次自动判断（含视觉补充）；不会无限重试 API。
- 后台权限、系统限制及本机 TTS 支持需要在你的手机上验证。
