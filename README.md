# 老年人手机助手

帮助不熟悉手机操作的老年人，用语音或文字说出目标，在真实 Android 页面上获得逐步指引，并在用户明确开启后使用有限的自动操作能力。

**当前手机版本：V0.3.0（versionCode 10，Android 11 及以上）。** 电脑日志查看器包含后续的完整截图适配、具体动作标题和整步复制更新。

本文是整个项目唯一的 README，兼作产品概览、使用指南、文件用途说明和入口导航。更新日期：**2026-11-06**。完整需求以 [PRD](docs/产品与进度/产品需求.md) 为准；“已实现”与“已经真机验收”分开说明。

## 2. 产品目标与使用场景

### 2.1 要解决的问题

老人知道自己想做什么，却不熟悉应该进入哪个应用、点击哪里，或者在页面变化后不知道下一步。手机助手围绕本次目标观察页面，提供目标高亮、简短文字和语音提示，并记录为何给出建议、是否执行以及怎样判断完成。

任务必须始终围绕用户表达的目标，不能擅自更换应用、渠道、联系人或操作对象。有歧义时应说明并澄清，不能猜测。

### 2.2 当前任务范围

支持语音或文字输入自定义目标，并保留“给女儿打视频电话”快捷任务，供原流程兼容和回归使用。固定快捷任务不代表所有自定义任务都使用同一个联系人。

当前提供 **13 项参数化只读流程模板**：

| 类别 | 流程模板 |
|---|---|
| 微信沟通 | 视频通话、语音通话、发送文字、发送照片 |
| 微信工具 | 打开扫一扫 |
| 系统沟通 | 普通电话、短信 |
| 手机设置 | 调大字体、调亮屏幕、调大媒体音量 |
| 日常使用 | 设置闹钟、查看最近照片、查看天气 |

模板保存语义步骤与联系人、内容、时间、城市等参数，不保存固定屏幕坐标。自定义目标会保守匹配模板；没有明确渠道时不擅自把“发消息”变成微信或短信，未匹配目标由模型根据实际页面处理。

**有模板不代表该类任务已经全面真机通过。** 目前不承诺任意应用、任意目标均能完成。

### 2.3 手机页面与入口

| 页面 | 用途 |
|---|---|
| 任务 | 语音/文字输入，核对或修改识别结果，启动自定义任务，使用固定快捷任务 |
| 我的 | 查看权限，配置模型、图片能力和自动操作开关，进入流程库与 Debug |
| 引导浮层 | 显示单步指引、高亮与语音，提供重试和停止；成功提示显示约 1 秒后关闭 |
| 流程库 | 查看只读模板，维护固定任务的流程版本、锁定、试运行与回退 |
| Debug | 查看本机技术日志、图树附件、指标，导出运行资料、填写验收标注和清理数据 |

Debug 是开发调试入口，不是面向老人的历史任务产品。

## 3. 当前如何观察、操作与判断完成

### 3.1 两种操作方式

| 能力 | 默认行为 | 限制 |
|---|---|---|
| 打开应用 | 优先调用实际可用的系统启动入口，然后观察前台页面 | 仅调用返回成功不能认定应用或整个目标已经完成 |
| 点击、返回 | 默认只给人工指引；在“我的”明确开启自动模式后才自动执行 | 自动执行后仍需观察和验证 |
| 输入、滚动 | 人工操作 | 当前没有自动输入、自动滚动 |
| 系统启动失败 | 根据自动开关和唯一可见图标条件，有限尝试 GUI 降级；否则提示人工处理 | 不编造包名、API 或 Deep Link，不无限反复尝试 |

模型返回 `click` 本身不会让人工模式自动点击。“展示建议”“操作已派发”“观察到页面变化”“任务完成”是不同状态。

### 3.2 一步任务的闭环

```text
观察页面 → 采集 UI 树和截图 → 检查是否对应稳定页面
→ 携带当前目标与过程摘要请求模型 → 校验建议及页面时效
→ 人工引导或允许的自动操作 → 观察操作与页面变化
→ 验证目标是否完成，否则继续下一步
```

- 每次用于决策的观察都会尝试保存截图，文本模型也保留本地图；截图已保存与已上传模型分别记录。
- 页面在采集或响应期间发生变化时，废弃过期结果并重新观察。截图失败、权限不足或树被截断都有具体原因。
- 空白 `target_node` 兼容为空节点；合法坐标仍可定位。未知/旧节点、越界、不重叠或过大的目标区域仍拒绝。
- 手机给出简短错误原因；日志保留失败阶段、错误码、规则、期望值、实际值和对应证据。
- 系统报告的点击、滚动、输入变化、返回键和窗口事件尽量关联当前建议；来源不确定时明确标注，不能由页面变化推断某次人工点击。

### 3.3 什么情况下算完成

完整目标恰好是“打开/启动某个已安装应用”时，可根据稳定的实际前台应用本地确认。**“打开设置并调大字体”不能仅因设置打开就结束。**

其他目标要求模型给出完成状态和非空的当前页面证据；文本模式还需有当前节点文字可以核对。图片模式的语义判断仍依赖模型，证据门槛不代表永远不会误判。

完成确认后优先更新界面，日志保存和成功复盘不应阻塞提示。已记录稳定等待、截图、请求排队、模型响应、完成确认到提示等分项时间，但尚无统一受控真机对比数据，不能把代码配置当作真实提速结果。

### 3.4 流程学习的范围

原固定视频任务支持成功复盘、新版本保存、自动启用、锁定、试运行和回退。锁定、停用或任务期间人工切换版本时，不应覆盖人工选择。

13 项新模板目前只读，不会因一次成功就自动学习晋升。复盘应使用真实轨迹和关联证据，不把未走过的捷径或来源不明的事件写成已确认经验。

详细规则见 [流程库说明](docs/技术设计/流程库.md) 和 [数据契约](docs/技术设计/数据契约.md)。

## 4. 安装、配置与开始使用

### 4.1 安装前

1. 使用 Android 11 或更新版本的手机。
2. 当前 V0.3.0 交付包与旧 V0.2.0 的调试签名不同，不能保证直接覆盖安装。先导出旧版需要保留的日志和流程；优先备用设备测试，或用原签名重新构建。不要未经保留数据就卸载旧版。
3. 准备自己的模型服务地址、模型名和 API Key，以及手机可访问的网络。
4. 通话、发消息等测试会影响真实联系人，应事先安排好测试对象。

### 4.2 配置助手

1. 安装当前 APK，在“我的 → 无障碍设置”启用服务，并确认已连接。
2. 填写 HTTPS 模型地址、模型名和 API Key。当前默认字段为 `https://api.deepseek.com` 与 `deepseek-flash`，实际服务和能力以账户情况为准。
3. 只有模型实际支持图片输入时才开启图片能力；文本模型不会因为保存了本地截图就自动收到图片。
4. 默认保持人工模式；需要自动点击和返回时，再明确开启相应开关。

API Key 在手机上加密保存，不需要填写到源码或 README。语音调用手机已有识别服务，可能联网；当前没有独立 ASR，也不保存录音。识别服务不可用时使用文字输入或键盘语音。

### 4.3 执行与停止

输入或说出目标 → 核对文字 → 开始引导 → 按当前方式操作。遇到错误先看具体原因和当前页面，再决定重试；“停止”结束引导并清除浮层。

任务、复盘与证据保存结束后，可以从 Debug 导出完整 ZIP。导出数据完整后，再用电脑查看。详细异常用例见 [安装与验收](docs/使用与验收/安装与验收.md)。

## 5. 电脑日志查看器怎么用

1. 打开 [日志查看器](日志查看器/index.html)。无需另外解压第二份查看器。
2. 将手机调试 ZIP 解压，选择一次运行的完整文件夹，包含 `events.jsonl`、UI 树 JSON 和截图；真实运行资料保存在本机，不随仓库公开。
3. 左侧按“第几步 · 具体动作”选择记录；尝试次数和请求编号保留在中间详情。
4. 中间查看过程、模型输入输出、UI 树和原始事件；右侧截图默认完整适配当前窗口，长日志在中间独立滚动。
5. 可以切换原图/节点叠加、筛选节点，点击图片与列表互相定位。点“放大查看”扩大图片区域，按 Escape 返回。
6. 点击“复制本步日志”，复制完整事件、模型内容、诊断和 UI 树。复制权限受限时提供手动弹窗；截图本体需另外附给 AI。

查看器本地读取，不自动上传，不修改原始日志。刷新后需要重新导入；旧日志原本缺失的截图无法补回。“已展示”不表示人已操作，“已派发”也不表示任务已完成。

更多说明见 [查看器使用说明](日志查看器/使用说明.md)。

## 9. 开发者构建与回归入口

本节命令从仓库根目录执行。需要 JDK17、Android SDK35、Build Tools35.0.0；工程使用 Gradle8.11.1、AGP8.9.2、Kotlin2.1.20。

先配置真实的 `ANDROID_HOME`，或自行创建本机有效的 `local.properties`。已删除的旧文件是另一台电脑的失效路径，不能照搬。

```sh
# 安卓单元测试、严格检查及构建
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug

# 日志统计工具测试
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tools -p 'test_*.py' -v

# 安卓测试报告汇总：先完成上面的安卓测试
python3 tools/summarize_android_tests.py
```

## 10. 数据、权限与保留规则

- 手机页面文字和启用的图片请求会发送给用户配置的模型服务；电脑查看器本身离线，不提供独立云端日志平台。
- 输入事件不保存密码、验证码等输入原文；可编辑字段值不写入树。但截图和其他页面文本仍可能含联系人、聊天或隐私信息。
- 无障碍事件只覆盖系统实际提供的信息，不能保证完整物理触摸轨迹，也不能完整记录所有返回手势。
- 安全窗口、系统权限、应用可见性、后台启动和第三方控件暴露情况会影响截图与执行。树图一致性检查不等于操作系统原子快照。
- 主动复制日志给 AI 或分享演示资料前，应检查其中的私人信息；不要把 API Key、签名私钥或私密运行日志当作公开源码资料。
- 当前源码、有效文档、真实日志和旧软件包保留；多余内容直接删除，不再另外生成备份档。`04_DEMO` 保持用户管理，本轮不检查、不修改。
