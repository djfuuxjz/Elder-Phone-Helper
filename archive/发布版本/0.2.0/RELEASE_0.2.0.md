# V0.2.0 · 语音自定义任务

更新日期：2026-10-20。Android 11+，包名 cn.elder.assistant，versionCode 9。与 V0.1.7 签名一致，满足覆盖安装条件。

## 使用方式

1. 更新安装 APK，保留现有模型配置与无障碍权限。
2. 在“任务”页点“语音输入任务”，通过手机已安装的语音识别界面说出目标，例如“打开设置调大字体”。
3. 识别文字回填后可修改，再点“开始引导”，核对目标并开始；助手返回桌面，由模型根据当前页面逐步提示，用户本人点击。
4. 也可以直接输入文字。语音取消、空结果、识别不可用不会启动任务或清除原草稿。
5. “给女儿打视频电话”集中在底栏上方，继续走原有固定任务与流程库。小屏大字或键盘压缩空间时，该快捷区移到滚动内容末尾，保持输入区域可用。

语音由手机识别服务负责，可能联网；本 App 不录制或保存原始音频，也未新增麦克风权限。此实现依赖手机安装了可处理 Android ACTION_RECOGNIZE_SPEECH 的服务，不保证每款 HyperOS 自带兼容服务。不可用时提示文字输入或键盘语音输入，不伪造识别结果。依据：[Android RecognizerIntent 文档](https://developer.android.com/reference/android/speech/RecognizerIntent)。

## 功能边界

- 保留橘猫、任务/我的、DeepSeek 配置、权限、Debug、停止/重试、目标高亮及人工点击模式。
- 自定义目标贯穿本次会话、模型请求、日志与完成状态，可观察其他 App；不自动点击、输入、滑动或系统返回。
- 固定任务仍直接请求系统打开微信。语音任务从桌面开始，按模型提示手动进入目标应用。
- 自定义任务不套用也不写入专用于女儿视频通话的流程库；固定任务的复盘、自动启用、锁定、回退保持原逻辑。多任务流程库尚未扩展。
- 模型请求间隔仍至少 1 秒；模型判定完成后保留 1 秒成功提示并关闭浮层。
- 不新增登录、用户任务历史或支付业务。当前自定义目标上限 500 字，不承诺所有任务或 App 均能完成。
