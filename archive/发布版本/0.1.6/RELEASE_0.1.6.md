# V0.1.6 暖色猫咪外观版

本次只修改展示层及版本号；模型、提示词、读屏、截图、目标坐标、校验、状态机、成功判定、流程库、日志和存储业务逻辑未改动。27 个非 UI/Overlay Kotlin 源文件的 SHA-256 与改版前完全一致，见 `test-results/ui-core-verification.json`。

## 外观变化

- 任务页：奶油白背景、深棕文字、原生矢量猫咪、暖橙大圆角主按钮；保留任务/我的双入口。
- 我的、权限与模型配置、Debug、流程库：统一暖色按钮、文字和背景；配置输入框采用白色圆角底。
- 引导浮层：猫咪＋圆角气泡；普通字号按钮并排，大字体或长标签上下排列。原有拖动把手、位置记忆、边界和目标避让保留。
- 去除旧提示四行上限；超长内容在气泡内滚动，拖动把手始终可用。短提示仍可直接拖动。浮层使用不透明紧凑底板，不向猫咪之外额外扩张透明触摸窗口。
- 所有原按钮文字、点击回调和显示状态保留；未新增业务功能或确认步骤。

## 本地验证

- 全部 145 项 Android 单元 / Robolectric 测试通过，0 失败、0 跳过；其中新增 3 项原生 View 渲染/交互测试。
- 新测试覆盖现有入口保留、猫咪不获取无障碍焦点、320×480dp 小屏 2 倍字体、长提示滚动、停止/重试按钮完整可见且至少 48dp、按钮回调和高亮不可触摸标志。
- 原有测试继续覆盖拖动边界、位置记忆、目标碰撞时停止入口、停止关闭/返回 App、成功提示定时关闭等。
- 严格 lint 与 APK 构建通过。Python 7 项、日志查看器 11 项及 Chrome 浏览器离线回归通过。
- 首轮 lint 发现绘制时分配对象，已改为缓存画笔/路径。日志查看器首次缺夹具/Playwright 路径，补齐原有固定日志样本与依赖后全通过；未删除、跳过或降低测试标准。

## 安装与待真机检查

APK：`../dist/phone-assistant-0.1.6-debug.apk`，包名保持 cn.elder.assistant，versionCode 从 6 升到 7，与 V0.1.5 签名一致，满足覆盖安装条件。直接安装更新，不卸载旧版；实际手机升级安装仍待验证。

1. 小米 15 覆盖安装后检查原模型配置、流程库和日志保留。
2. 正常/最大系统字体下，检查任务、我的、Debug、流程库和编辑对话框，滚动查看全部控件；打开键盘检查输入框与按钮可达。
3. 微信引导时拖动把手/短提示，检查边缘限制、下一步位置记忆；长气泡上下滚动读到末尾。
4. 检查高亮框位置、目标点击透传、浮层外空白区域可操作、浮层避让目标，以及按钮不误触拖动。
5. 点停止：浮层立即关闭并返回 App；点击重试/从当前页开始仍执行原流程。
6. 完成视频呼叫：出现成功文字，约 1 秒后关闭浮层，不继续指引；检查原语音播报。

这些实机项尚未执行，不计作通过。真实 API / 微信完成率也未重新测量。
