# V0.1.5 优先点击返回按钮

Android 11+，versionCode 6，与V0.1.4同签名，可覆盖安装。

- 返回操作优先使用页面可见返回箭头/按钮，其次屏幕上实际可见的系统返回键，最后才考虑全面屏手势。由模型结合实际页面判断，不固定猜测左上角坐标。
- BACK动作现在与CLICK、INPUT一样显示目标高亮。无文字ImageView或基于截图的有效坐标都支持，不恢复文字标签硬校验。
- 模型返回BACK但没给位置时，先补充一次定位要求；启用图片能力时请求截图。无图片能力时只补充一次文字请求；已提供图片或达到本步请求限制时不循环补图，允许模型说明系统返回方法。
- 返回定位请求记录return_location_requested和步骤摘要，后续复盘也保留优先点击返回按钮的偏好。既有已学习流程不被批量重写，新提示对其继续生效。
- 用户亲自点击；没有增加自动点击、自动系统返回或自动手势。其余V0.1.4行为保留：模型声明完成、1秒关闭浮层、复盘自动启用。

## 真机复验

覆盖安装后从微信文件消息页启动，检查优先引导页面返回按钮并高亮。若初次只返回back/null，日志应有return_location_requested，下一次请求应含补充要求（启用图片时含截图）。检查不反复补图、不把未显示的系统返回键当成存在。
