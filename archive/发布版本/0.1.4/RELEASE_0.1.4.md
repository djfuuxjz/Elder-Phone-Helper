# V0.1.4 模型判断与流程自动学习

日期：2026-10-19。Android 11+；包名cn.elder.assistant；versionCode 5。与V0.1.3同签名，可以覆盖安装。

## 本次确认并实现的变更

- 删除输入框、搜索/放大镜、聊天页更多信息的本地业务拦截与自动纠正。模型返回的目标通过基础检查后直接用于引导，不再因无文字、不是EditText、不是App识别的加号而被拒绝或改写。
- 删除所有基于本地页面词语的完成检查、截图二次确认和本地主动识别成功。模型输出complete且task_completed=true就终止；保留字段一致性、有效目标和过期响应检查。模型若误报成功，App也会结束，不能把完成日志等同于人工真机验收。
- 完成后仍取消旧请求和轮询，显示“任务已成功”1秒后关闭悬浮窗。完成证据照常入日志，method=model_decision。
- AI复盘总结尽可能短的语义流程，去掉重复/错误/绕路。新版本与启用状态在同一原子写入中保存，下次任务自动携带它；旧版本、基础版本、来源运行和理由保留，可回退。
- 保留人工选择：当前版本被明确锁定、流程被停用或任务期间切换版本时，复盘只保存，不覆盖当前选择。内置版本默认内容锁定不阻止正常学习；开发人员显式锁定后也可保护其启用状态。试运行版本与当前启用版不同的情况下同样只保存。
- 最短路线是AI基于本次记录的归纳，不证明全局最优。未实际走过的捷径要求标记尚未验证；模型自身正确性仍需真机反馈评估。
- 本次没有删除联系人检索阶段的滑动限制。固定联系人名、confidence最低门槛仍不存在。保留JSON/类型/长度、坐标有效性、节点当前性、点击目标面积、过期结果检查；图片和输入定位业务校验已移除。
- 日志查看器可直接显示“已自动启用”，复盘请求仍有独立request_id，发送至少间隔1秒。

## 安装后检查

1. 覆盖安装，开启无障碍并启动任务；之前右上角放大镜步骤不应再出现“空白容器”拒绝。
2. 检查输入和聊天页指引采用模型的目标，没有被App强制改到另一控件。
3. 模型宣告完成后，应显示成功1秒并关闭；查看日志method=model_decision。模型误报完成时也请保留日志反馈。
4. 等待后台复盘完成，在“我的 → 流程库”看到新的已启用版本。再启动一次，request.input中的workflow.version应使用这个新ID。
5. 手动回退、锁定、解锁；确认锁定时复盘仍保存，但不自动替换；完成后导出日志用新版查看器查看。
